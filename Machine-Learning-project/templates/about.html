About CivicFix

A machine learning project built on NYC 311 civic complaint data

What is CivicFix?

CivicFix is an AI-powered civic complaint management system built on top of New York City's 311 service request dataset. It uses machine learning to predict the resolution status of a complaint — whether it will be Closed, In Progress, or Open — based on the type of issue, location, agency and other factors.

The Problem
  • New York City receives millions of 311 complaints every year
  • Citizens have no idea when their complaint will be resolved
  • Manual triage of complaints is slow and inconsistent
  • Different agencies handle different types of issues — routing can be wrong
  • There is no automated priority assignment based on complaint type
Our Solution
  • Train ML models on 50,000 real NYC 311 records
  • Predict complaint status automatically before resolution
  • Auto-assign the correct department based on complaint type
  • Visualise patterns — which areas, agencies and issue types have most complaints
  • Give citizens and managers a clear, easy-to-use dashboard
